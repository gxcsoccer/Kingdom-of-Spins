# 3 分钟演示脚本

线上地址：https://kingdom-of-spins.deskmind-site.workers.dev
建议设备：笔记本，Chrome 浏览器，外接音箱（有语音解说和音效）。开场前先在地图页勾选「演示模式」：解锁全部对手，比赛改为先拿 2 分获胜。

| 时间 | 画面 | 讲什么 |
|---|---|---|
| 0:00–0:20 | 标题页 | 这是我儿子设计的陀螺游戏，玩法规则是他写的：融合陀螺、收集、招募对手。AI 和真实物理让它变成一个“边玩边学”的科学游戏 |
| 0:20–0:50 | 选 Dragoon → 挑战小岚 → 发射小游戏，**对着麦克风喊“3, 2, 1, Go Shoot!”** | 对战不是动画，是 MuJoCo 刚体物理每秒算 4000 次。点 2× 加速 |
| 0:50–1:30 | 结算页 → 复盘 | AI 自动挑出关键时刻，点 ① 慢动作回放，解说员念出解说词。孩子先做“你猜？”题，答完揭晓原理，再给一个生活中的例子 |
| 1:30–2:10 | 科学实验室：把平轴换成圆轴，预测“会更好”，开始实验 | 浏览器同时跑 6 场：原版 3 场、改装版 3 场，发射条件完全相同，只改一个变量。博士解释结果，以及为什么要重复做 3 次 |
| 2:10–2:45 | 融合工坊：Fish + Dragoon，按住 🎤 说“我想要像鱼一样滑、能把阿铁撞飞的”（或者拍照上传一张画） | AI 设计 2–3 个各有取舍的方案，转动惯量是根据参数实际算出来的；只有 Blade 融合，孩子定的规则 |
| 2:45–3:00 | 对战模式 → 联机房间码 | 用房间码约朋友联机；两边浏览器各算一遍同一份物理，服务器核对结果。物理是理想化模型，会如实告诉孩子“在这个模型里” |

## 备用方案
- 网络断了：对战和实验都在浏览器本地计算，可以照常演示；AI 会回退到模板文案。
- 麦克风没反应：直接点 GO SHOOT! 按钮。
- 万一页面卡住：刷新即可，存档保存在本机。
