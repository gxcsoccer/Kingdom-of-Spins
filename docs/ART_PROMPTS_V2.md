# 陀螺王国 · 美术需求提示词 v2

**为什么要改：** v1 的地图是黑白中国水墨山水，中间大片留白，人物却是彩色日式动画，两种画风放在一起很违和；地图上也看不出任何和陀螺有关的东西。v2 统一成**全彩日式少年动画游戏风**；玩法也改成“世界总图选区域 → 进入区域由 AI 自由探索”，所以总图改为 3 个地貌区域（海岸港湾 / 高山冰川 / 火山），并给区域定好位置，方便代码放入口和进度徽章。

**探索场景改为预先设计**（第 3c 节，28 张），AI 只负责每次探索的剧情、藏宝位置和对话；只有“科学绘本”里讲任意知识点的插图仍由 AI 实时生成。

**真实原型：** 三个区域在游戏里是架空的，但各有一个真实原型，用来带出真实的地理知识。区域场景要能看出原型的标志性特征，但不必照搬：

| 游戏区域 | 真实原型 | 画面上要体现的原型特征 |
|---|---|---|
| 新手港湾 | 法国圣米歇尔山 | 海湾中央一座尖顶修道院小岛，涨潮时四面是水，退潮时露出一条沙滩小路 |
| 雷霆山脉 | 喜马拉雅山脉 / 珠穆朗玛峰 | 一座明显最高的金字塔形雪峰，山脚到山顶依次是森林、草甸、裸岩、冰雪，能看出雪线和冰川 |
| 龙焰火山岛 | 夏威夷群岛 | 宽缓的盾形火山，熔岩流入大海冒出白色蒸汽，黑沙滩，椰子树 |


**保留不动：** 10 个对手立绘、融合博士 3 张、Logo、陀螺立绘、徽章，这些已经符合 v2 风格。**玩家头像 4 张需要重画**（见第 5 节：和 NPC 撞色、撞造型）。
**需要重画或新增：** 世界总图（P0）、**28 张探索场景（P0）**、3 张区域封面（P1）、3 张真实原型档案图 + 地球仪图标（P1）、3 张场景背景（P1）、地图地标图标（P1）。

## 3c. P0 · 探索场景图库 —— `scenes/<区域>/<场景>.jpg`，1024×768（4:3），JPG

探索玩法改成**预先设计好的场景**：孩子在场景之间走动（每个场景有固定出口），点画面里的物体去调查，AI 主持人每次把陀螺、对手、线索藏在不同的地方。所以**这 28 张图就是探索玩法的门面**，请按最高品质制作。现在仓库里已有一版 FLUX.2 生成的占位图（`public/art/scenes/`），可以对照着重画同名文件直接替换。

**品质要求（每张都要满足）**

- 画风严格遵守第 0 节的统一画风，28 张放在一起要像同一部动画里的场景：同样的线条粗细、上色阶数、光源方向（左上）、色彩饱和度。
- 构图：3/4 视角的场景插画，主体占满画面，前景不要站人（人物由游戏另外叠加）；远景简单，不要过度杂乱。
- **画面里绝对不要出现文字**（招牌、地图、表格上都不要字，用图形代替）。上一版占位图的集市招牌、渔具店图表出现了乱码，这是最常见的问题。
- **下表列出的“可点物体”必须画出来，并放在指定位置附近**（误差 5% 以内），代码会在这些位置放可点的热点。物体要清楚、好认，不要被别的东西挡住。
- 同一区域的场景要有连续性：新手港湾统一是晴朗上午；雷霆山脉越往高处越冷越有雪，雷霆塔和雷暴山脊可以是阴天暴风。
- 涨潮（high_tide）和退潮小路（tidal_path）是同一个海湾，修道院小岛的造型、位置要一致，只是水位不同；这两张用来教潮汐。

**通用提示词模板**：`【画风】（第 0 节）+ 场景插画，3/4 视角，1024×768，主体占满画面，前景不要人物，不要任何文字。场景：<下表的场景描述>。画面中必须清楚画出：<可点物体及位置>。`
