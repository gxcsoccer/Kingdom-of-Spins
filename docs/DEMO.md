# 3 分钟演示脚本（2026-10-11 晚版）

线上地址：https://kingdom-of-spins.deskmind-site.workers.dev
设备：笔记本 + Chrome，外接音箱（有博士配音、音效）。联机环节需要第二台设备（或另一个浏览器的无痕窗口）。

## 开场前准备（5 分钟）
1. 家长 Google 登录 → ⚙ 管理档案（乘法题验证）→ 给演示档案点「🎬 导入演示存档」：6 只陀螺（含设计的「雷龙小勇士」和改装版）、队员冰见和雷牙、港湾已通关、演示模式开启。
2. 第二台设备登录另一个孩子档案，停在「对战模式 → VS 朋友」。
3. 打开声音；确认麦克风权限（喊口令发射用）。
4. **演示中不要刷新页面**（结算页没有独立网址，刷新会回到对战开场）。

## 流程
| 时间 | 画面 | 讲什么 |
|---|---|---|
| 0:00–0:20 | 标题页 → 世界地图 | 这是我儿子设计的陀螺游戏：规则是他定的——找陀螺、融合、招募对手组队。地图三个区域对应真实地理（圣米歇尔山、喜马拉雅、夏威夷） |
| 0:20–0:55 | 雷霆山脉寻宝：跟着「先去「X」↗」走路牌，开🔊朗读，点 💡 物体解锁知识卡，海拔变化弹出冷暖 | 寻宝的位置、线索、冷热是**代码决定**的，照着走一定能到；AI 只负责讲故事。点物体是“发现”，💡 物体会解锁真实地理知识 |
| 0:55–1:30 | 挑战职业对手：「谁上场？」选冰见 → 「冰见：疾风发射！」切入 → 3D 对战 | 对战是 MuJoCo 刚体物理每秒算几千次，不是动画。队员的专长来自真实发射参数（转速、倾角、瞄准），讲得通物理 |
| 1:30–2:05 | 结算 → 复盘（先猜再揭晓）→ 实验室：换轴尖，看「改装更强！⬆」→「🔧 装上这个改装」→「⚔️ 带改装版再战」 | 同一个发射、只改一个变量，跑 3 次对照实验；结论由数据算出，AI 不能和数据矛盾。实验 → 改装 → 实战验证，是完整的科学方法 |
| 2:05–2:40 | 融合工坊：Dragoon + Fish，输入或说“黑红配色、龙爪一样的刃、闪电花纹、超级攻击” → 三张英雄卡（鼠标悬停转起来）→ 选一张 → 预测 →「带它试一场」 | AI（Claude）把孩子的话变成外观设计；转动惯量、重量是代码按参数算的；也可以拍一张画（⌘V 粘贴）让 AI 看图做陀螺 |
| 2:40–3:00 | 对战模式 → VS 朋友：两台设备同时「准备好了！」→ 同步倒数 → 拉弹弓时能看到对方力度 | Cloudflare Durable Objects 房间：服务器只发同一个随机种子，两边浏览器各算同一份确定性物理再核对。只能用房间码邀请，没有陌生人匹配 |

## 一句话讲清 AI 用在哪
- **AI 负责“想”和“讲”**：融合设计（Claude Sonnet）、看画做陀螺、复盘讲解与出题、实验讲解、绘本好奇心支线；博士配音（Fish Audio 预生成）。
- **代码负责“对错”**：物理结果、寻宝线索、实验结论、输赢——AI 不能改。
- 物理是**理想化模型、未经实物校准**：界面上都标注“在这个模型里”。

## 备用方案
- 网络断了：对战、实验都在浏览器本地计算；AI 功能自动换成公式方案 / 模板文案。
- 麦克风没反应：直接拉弹弓或点按钮。
- 联机第二台设备没准备好：跳过联机，展示对战模式首页即可。
- 绘本支线只演示 1 层，点一次就「↩ 回到主线」。
